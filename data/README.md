# data/

Everything in this directory is downloaded or derived by the scripts and
is **not** tracked by git. After running the full workflow you will have:

```
outlines/   17_rgi60_SouthernAndes.zip (RGI cache) + olivares_glaciers.geojson
appeears_tasks.json          IDs of the submitted AppEEARS tasks
raw/MOD10A1/*.nc             daily snow albedo, clipped to the study area
raw/MCD43A3/*.nc             black/white-sky shortwave albedo, clipped
processed/albedo_timeseries.csv   glacier-mean daily albedo, all products
```
